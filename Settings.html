Dropdown Lists

Add, rename, reorder or delete values. Renaming a value also updates existing enquiries and history. Won / Lost / Closed are locked.

Required Fields

Tick a field to make it required, untick to make it optional. Forms show a red * on required fields and the server enforces the same rules.

Status Rules

Controls what must happen before a status can be set.
Won Verification
ON: an enquiry cannot be marked Won until Bill Details are submitted. The Bill pop-up opens when Won is selected.
OFF: Won can be selected directly with no bill. Dashboard Won sales then fall back to the Quotation Amount.
Reset verification when an enquiry leaves Won
If an admin moves an enquiry from Won to another status, clear its Verified flag so a bill must be submitted again before it can be Won again.
Admin-only statuses
Only admins can set these statuses, and only admins can update an enquiry that is already in one of them.

Bill Upload

Where bills are stored and what is accepted.
Changing the name renames the existing folder, so old bills stay together.

Admins

Admins can set admin-only statuses such as Closed. The owner is always an admin.

Web App & Security

The Web App lets other users add data through the forms while the sheets stay protected.
